# 合约仓位计算器

面向 Web 与 iOS 主屏幕的静态合约仓位计算器。纯浏览器计算，无账号、无服务器、无外部依赖。输入会保存在本机浏览器中。页面优先展示所需保证金和计划止损金额；填写开仓价与止损价后自动判定方向。页面通过 `prefers-color-scheme` 跟随设备自动切换浅色和深色模式。

## 公式与单位

严格依照指定公式：

- 止损量（USDT）= 全仓仓位（USDT）× 风险百分比 / 100
- 止损距离比 = |开仓价 − 止损价| / 开仓价
- 仓量 / 所需保证金（USDT）= 止损量 / (止损距离比 × 杠杆倍数)
- 名义仓位（USDT）= 仓量 × 杠杆倍数
- 合约数量（标的单位）= 名义仓位 / 开仓价

“全仓仓位”作为可用资金输入，同时是风险百分比的计算基数。输入中的风险百分比是账户资金风险比例。

止损价低于开仓价时自动判定做多，高于开仓价时自动判定做空；两者相同无有效止损距离。结果未计手续费、滑点、资金费率、保证金率、强平和交易所最小下单单位。全仓模式的其他持仓会共享保证金，不能用此计算器推断强平安全性。

## 运行与发布

将本目录作为静态站点上传到 Netlify；发布目录即本目录，无构建命令。用 iOS Safari 打开后，可通过“分享 → 添加到主屏幕”安装。需要 HTTPS 才能启用离线缓存。更新后的缓存采用网络优先策略。

本地预览：`python -m http.server 8080`，访问 `http://localhost:8080`。

运行公式测试：`node --test tests/*.test.mjs`。

图标源文件是 `icon.svg`，同设计的 PNG 主屏幕图标可运行 `python scripts/render_icon.py` 重新生成（需要 Pillow）。
