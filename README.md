# 仓位罗盘

面向 Web 与 iOS 主屏幕的静态合约仓位计算器。纯浏览器计算，无账号、无服务器、无外部依赖。输入会保存在本机浏览器中。

## 公式与单位

严格依照指定公式：

- 止损量（USDT）= 开仓价格（USDT）× 风险百分比 / 100
- 止损距离比 = |开仓价 − 止损价| / 开仓价
- 仓量 / 所需保证金（USDT）= 止损量 / (止损距离比 × 杠杆倍数)
- 名义仓位（USDT）= 仓量 × 杠杆倍数
- 合约数量（标的单位）= 名义仓位 / 开仓价

“全仓仓位”作为可用资金输入，用于显示保证金占用和实际账户风险比例，不改变上述公式。输入中的风险百分比**以开仓价格为基数**，不是账户资金风险比例。若后者才是需求，应将第一式改为“全仓仓位 × 风险百分比 / 100”。

做空时使用绝对止损距离；止损价格须位于开仓价的亏损方向。结果未计手续费、滑点、资金费率、保证金率、强平和交易所最小下单单位。全仓模式的其他持仓会共享保证金，不能用此计算器推断强平安全性。

## 运行与发布

将本目录作为静态站点上传到 Netlify；发布目录即本目录，无构建命令。用 iOS Safari 打开后，可通过“分享 → 添加到主屏幕”安装。需要 HTTPS 才能启用离线缓存。更新后的缓存采用网络优先策略。

本地预览：`python -m http.server 8080`，访问 `http://localhost:8080`。

运行公式测试：`node --test tests/*.test.mjs`。
